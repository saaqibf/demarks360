# Landing page footage drop zone

Drop the client's real files here with these exact names and the landing page
picks them up automatically (no code changes, redeploy required):

| File            | Where it appears                              | Ideal content                                   |
|-----------------|-----------------------------------------------|-------------------------------------------------|
| hero.mp4        | Hero backdrop behind the golden ring          | 10-20s loop, dark/moody wide shot of the booth spinning at an event |
| step-1.mp4/.jpg | "Step on the platform" frame                  | Guest stepping onto the platform                |
| step-2.mp4/.jpg | "The camera orbits" frame                     | The slow-mo spin itself, confetti mid-air       |
| step-3.mp4/.jpg | "Leave with the video" frame                  | Guests watching/receiving the video on a phone  |
| gallery-1..5    | "Fresh reels" gallery (.mp4 or .jpg each)     | One clip/still per real event (portrait 3:4)    |

Rules of thumb: mp4 beats jpg wherever both exist (video renders on top).
Keep clips short (5-15s), under ~8 MB each, H.264, no audio needed (they play muted).
Portrait 3:4 for gallery, landscape 4:3 for steps, 16:9 for hero.
If a file is missing the designed placeholder shows instead, so partial delivery is fine.
